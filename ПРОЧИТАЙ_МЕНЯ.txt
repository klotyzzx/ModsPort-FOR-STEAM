МОДОПОРТ 2.0 — загрузчик Steam Workshop для любых игр
Windows 10/11 • Python 3.10+ • интерфейс на русском

БЫСТРЫЙ СТАРТ
1. Установи Python с https://www.python.org/downloads/windows/
   Нужны Python 3.10+, компонент Tcl/Tk (обычно включён) и Python Launcher / PATH.
2. Распакуй ВСЮ папку из ZIP. Запусти «Запустить.bat».
3. Вставь ссылку на коллекцию ИЛИ на отдельный мод из Steam Workshop (кнопка «Вставить»),
   выбери папку и нажми «Скачать». Игра определяется автоматически.
4. Первый запуск скачает официальный SteamCMD. Вход только anonymous:
   пароль, аккаунт и Steam Web API key не нужны.

ЧТО НОВОГО В 2.0
• Работает с ЛЮБОЙ игрой из Steam Workshop, а не только с Project Zomboid.
• Принимает ссылку на коллекцию или на одиночный мод.
• Кнопка «Проверить»: показывает игру, название и список модов БЕЗ скачивания.
• Таблица модов со статусом каждого: ожидает / скачивается 45% / готово / ошибка.
• Журнал без мусора: в окне только значимые события, строки прогресса SteamCMD
  не пишутся. Сырой вывод SteamCMD включается галочкой «Подробный вывод».
• Причины ошибок объяснены по-русски (например, «Steam не отдаёт этот мод без аккаунта»).
• Журнал каждого запуска — отдельный файл; хранятся последние 10.
• Папка результата называется «Игра - Коллекция (дата)».
• Новый внешний вид, кнопка «Скрыть журнал», Enter в поле ссылки = «Проверить».

ВАЖНО ПРО АНОНИМНЫЙ ДОСТУП
Многие игры не отдают Workshop анонимному входу — тогда мод получит ошибку,
остальные продолжат скачиваться. Это не обходится. Частные, удалённые и
ограниченные элементы недоступны. Программа не скачивает саму игру и не обходит
проверку владения. Поддерживается только Steam Workshop; другие сайты с модами
(Nexus, CurseForge и т.п.) не поддерживаются.

ЧТО ПОЛУЧИТСЯ
В выбранной папке создаётся отдельная папка результата. Внутри — числовые папки
Workshop-элементов с исходной структурой, отчёт collection.json и инструкция
КАК_ИСПОЛЬЗОВАТЬ.txt. Вложенные коллекции раскрываются, дубли ID исключаются.
Общий индикатор показывает количество обработанных модов, НЕ байты.
Ошибки отдельных модов не останавливают остальные. Успехом считается только
сообщение SteamCMD об успешной загрузке, а не наличие старых файлов.
Вся очередь идёт одной сессией SteamCMD. По умолчанию полная проверка выключена.

УСТАНОВКА В ИГРУ
Это загрузчик, НЕ менеджер модов. Как подключать моды, зависит от игры: смотри
описание мода и инструкцию автора. Для Project Zomboid в КАК_ИСПОЛЬЗОВАТЬ.txt
добавляется отдельная подсказка. EXE, DLL и скрипты из модов программа НЕ
запускает. Моды — сторонний код: включай только от авторов, которым доверяешь.

ПОВТОРНЫЙ ЗАПУСК И ОСТАНОВКА
Каждая загрузка создаёт новую папку, старые не перезаписываются. SteamCMD
использует собственный кэш. Новая попытка снова обрабатывает всю коллекцию.
«Остановить» завершает SteamCMD; уже скопированные моды сохраняются.
Запрос к Steam API может останавливаться не мгновенно (таймаут до 40 с, с повторами).
Если SteamCMD молчит 20 минут, элемент завершается ошибкой.
При закрытии окна во время работы сначала останови загрузку.

ПАПКИ
SteamCMD: %PUBLIC%\PZCollectionLoader\steamcmd (обычно C:\Users\Public\...).
Настройки и журналы: %LOCALAPPDATA%\PZCollectionLoader (журналы — в подпапке logs).
Папки названы по-старому намеренно: кэш SteamCMD и настройки от версии 1.1 подхватятся.
Кэш SteamCMD остаётся после копирования; нужно место под кэш И под результат
(примерно двойной объём модов). Когда кэш не нужен, его можно удалить целиком.

НЕПОЛАДКИ
• Окно не открылось: открой bat, прочитай сообщение; проверь наличие Tcl/Tk.
• Steam API недоступен: проверь интернет и публичность ссылки.
• «Не отдаёт без аккаунта» / «нужен аккаунт с игрой»: ограничение Steam для этой игры или мода.
• Нужны подробности: включи «Подробный вывод SteamCMD» или нажми «Файл журнала».
• Журналы могут содержать локальные пути: проверь их перед отправкой кому-либо.

Проверены синтаксис и вспомогательные функции вне Windows. Полный запуск
интерфейса и реальное скачивание через Windows SteamCMD в среде подготовки
не выполнялись.

ПЕРЕХОД С ВЕРСИИ 1.1
Закрой старую версию, распакуй 2.0 отдельно и запусти её bat. Файл «Запустить.bat»
не менялся. Старые папки результатов не трогаются.
